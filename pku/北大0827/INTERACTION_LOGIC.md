# SoulAgent 交互逻辑说明

> 版本：北大0827
> 更新：2026-08-30
> 范围：侧边栏 · 新建对话 · 历史对话 · AI分身广场 · 创建分身
> 不含：定时任务、帮我听会

---

## 一、整体页面结构

所有页面由两部分组成：**左侧固定侧边栏** + **右侧主内容区**。

侧边栏始终可见，不随主内容变化而收起。

---

## 二、侧边栏

### 2.1 结构（从上到下）

```
Logo（北大标识，可点击）
─────────────────────────
✦ 新建对话
─────────────────────────
AI分身
  ├─ 我的分身 1
  ├─ 我的分身 2
  └─ + 创建分身
─────────────────────────
历史对话
  ├─ 对话 A
  ├─ 对话 B
  └─ ...
```

### 2.2 Logo 点击

跳转到新建对话页（同「新建对话」按钮）。

### 2.3 新建对话按钮

| 当前所在页面 | 点击结果 |
|------------|---------|
| 已在新建对话页 | **不跳转**，原地清空输入框，推荐问题重新随机刷新 |
| 其他任何页面 | 跳转到新建对话页 |

> 设计意图：避免用户反复点击产生多余的空白页面。

### 2.4 AI分身区（我的分身）

- 展示用户已创建并**构建完成**的分身，构建中的分身不在此显示
- 每个分身以小头像 + 名称展示
- 点击某个分身 → 进入该分身的「新建对话页」（非历史记录，是全新的空白对话起点）
- 「+ 创建分身」→ 跳转创建分身页

### 2.5 历史对话列表

- 按创建时间倒序排列，最新的在最上面
- 每条历史对话**带有类型标识 Badge**，用于区分这是和谁聊的：

  | 对话类型 | Badge 样式 |
  |---------|-----------|
  | 与主 AI 助手聊（Agent 对话） | 默认气泡图标，无文字 |
  | 与某个专家分身聊 | 该专家的彩色胶囊，文字为专家名字 |
  | 与我的某个个人分身聊 | 该分身的彩色胶囊，文字为分身名字 |
  | 群聊（多专家） | 暗红色胶囊，文字「群聊」 |

- 点击历史条目 → 进入对话详情页，恢复完整聊天记录
- 当前正在查看的对话条目高亮显示

### 2.6 侧边栏实时更新

以下操作会实时触发侧边栏刷新，无需手动刷新页面：

- 发送第一条消息后（新会话出现在历史列表）
- 创建/完成构建分身（分身列表更新）
- 修改分身基本信息（名称变更同步显示）

## 三、对话的两种类型

系统中所有对话分为两大类，**UI 样式和交互规则都不同**：

### 类型 A：与 Agent 对话（主 AI 助手）

- 入口：点击「新建对话」按钮
- 特点：AI 以 SoulAgent 身份回复，用户可以在对话中通过 @ 召唤专家或个人分身协同参与
- 历史记录 badge：气泡图标（无彩色标签）

### 类型 B：与分身 1v1 对话

分为两种子类型：

| 子类型 | 说明 | 入口 |
|-------|------|------|
| 个人分身对话 | 我自己创建的分身 | 侧边栏点击分身 |
| 专家分身对话 | 平台上的专家 AI 分身（如教授、研究员） | AI分身广场点击专家卡片 |

- 特点：只有这一个分身/专家在对话，无法 @ 其他人，底部工具栏也不显示 @ 按钮
- 历史记录 badge：该分身/专家的彩色标签

## 四、新建对话页（与 Agent）

**入口**：「新建对话」按钮、Logo 点击

### 4.1 页面内容

- 标题：「TY，今天需要帮你做什么」
- 输入框（支持多行输入）
- 底部工具栏：附件 / AI分身选择器（@ 召唤）
- 推荐问题卡片：随机展示 3 张

### 4.2 核心规则：先发消息，再创建对话

> 打开此页面时，侧边栏历史列表**不会出现任何新条目**。
> 只有用户发送了消息，才会创建对话记录，并跳转到对话详情页。

这与常见 IM 工具不同——用户打开页面只是在「起草」，不是「新建」。

### 4.3 发送消息的完整流程

1. 用户在输入框填写内容（或点击推荐问题卡片自动填入并发送）
2. 点击发送（或按 Enter）
3. 系统自动提取会话标题：取消息前 20 个字，若标题重复则自动加「(1)」「(2)」区分
4. 若消息中包含 `@分身名` 或 `@专家名`，AI 回复会以「协同咨询」格式呈现（见第六节）
5. 创建对话记录，**立即跳转**到对话详情页
6. 侧边栏历史列表实时更新，出现这条新记录

### 4.4 @ 召唤分身/专家

- 点击底部「AI分身」按钮，弹出下拉菜单，分两组：
  - 「我的分身」（已完成构建的个人分身）
  - 「专家分身」（平台预置专家）
- 选中后，自动在输入框开头插入 `@名字 `
- 也可直接手动打 `@名字`，效果相同

### 4.5 推荐问题卡片

- 每次展示 3 张，从题库中随机抽取
- 点击卡片 → 自动填入问题并**立即发送**（无需再次点击发送）
- 在新建对话页点击「新建对话」按钮，卡片会**重新随机刷新**

### 4.6 快捷键

| 按键 | 行为 |
|------|------|
| `Enter` | 发送消息 |
| `Shift + Enter` | 输入框内换行 |

## 五、新建对话页（与分身/专家）

**入口**：侧边栏点击我的分身 / AI分身广场点击专家卡片

### 5.1 页面定位

这是**每个分身/专家独立的「欢迎页」**，类似于和某个人聊天前的介绍页面。

打开时历史记录同样不变，发送第一条消息后才创建对话并跳转。

### 5.2 页面内容

- 分身/专家介绍卡片（居中展示）：
  - 头像、名字
  - 职称标签 + 研究领域标签
  - 简介描述
  - 3 个推荐问题（点击自动填入并发送）
- 输入框 + 发送按钮

### 5.3 个人分身 vs 专家分身的差异

| 细节 | 个人分身 | 专家分身 |
|------|---------|---------|
| 右上角按钮 | 「管理分身」+「申请上架」 | 无 |
| 左上角按钮 | 无 | 「返回 AI 分身广场」 |
| 头像形式 | 自定义文字头像 | 人形图标 |
| 角色标签颜色 | 粉色（「专属AI分身 · 我的分身」） | 红色（职称） |

### 5.4 申请上架按钮（仅个人分身）

| 状态 | 按钮显示 |
|------|---------|
| 未申请 | 「申请上架到AI分身广场」（可点击） |
| 审核中 | 「上架审核中」（禁用，不可点击） |
| 已上架 | 「已上架至广场」（绿色状态标识） |

点击申请 → 弹出弹窗，填写联系方式和申请说明 → 提交后进入审核中状态。

## 六、对话详情页

**入口**：发送第一条消息后自动跳转 / 点击历史对话条目

### 6.1 页面结构

- **顶部栏**：返回按钮（回到分身广场）+ 会话标题
- **消息区**：可滚动，新消息出现后自动滚动到底部
- **底部输入框**：始终固定在底部

### 6.2 顶部介绍卡（分身/专家对话时显示）

当这是一个与具体分身或专家的 1v1 对话时，消息列表**顶部**会展示该分身/专家的介绍卡片（同新建对话页的介绍内容），并附带 3 个推荐问题可快速发送。

纯 Agent 对话和群聊不显示此卡片。

### 6.3 消息样式（按对话类型）

**与 Agent 对话**

- 用户消息：右侧，灰色圆角气泡
- AI 回复：左侧，无头像，文字直接展示
- 若有 @ 协同咨询，AI 回复内嵌「专家/分身引用块」（带左侧彩色竖线边框）

**与专家分身 1v1 对话**

- AI 回复：左侧，带该专家的**彩色小圆头像**
- 无 @ 功能，底部工具栏只有附件按钮

**与个人分身 1v1 对话**

- AI 回复：左侧，带该分身的**彩色字母头像**
- 无 @ 功能，底部工具栏只有附件按钮

**群聊**

- 无顶部介绍卡
- 每条 AI 回复都带**专家姓名 + 职称标签**，不同专家用不同颜色头像区分
- 多位专家会**依次**回复，每人回复前先显示「正在思考...」打字动效

### 6.4 底部工具栏可见性

| 对话类型 | 帮我听会按钮 | @ 召唤按钮 |
|---------|------------|----------|
| Agent 对话 | 显示（忽略） | 显示 |
| 个人分身 1v1 | 隐藏 | 隐藏 |
| 专家分身 1v1 | 隐藏 | 隐藏 |
| 群聊 | 显示（忽略） | 显示 |

### 6.5 在 Agent 对话中 @ 召唤（协同咨询）

选择分身或专家后，发送的消息会触发「协同咨询」回复，格式固定为：

1. 「帮你咨询了 XX（职称/角色），回复如下：」
2. 被咨询方的专业意见（带边框引用块）
3. AI 的进一步补充分析 + 追问引导

### 6.6 群聊的多专家顺序回复

进入群聊对话时，若用户发送了消息但专家还未全部回复，会自动触发多轮顺序回复：

- 每位专家依次出现
- 回复前显示「正在思考并组织见解...」动效约 1 秒
- 全部专家回复完毕后，输入框恢复可用

## 七、AI 分身广场

**入口**：侧边栏「AI分身」标题（点击）

### 7.1 两个 Tab

| Tab | 内容 |
|-----|------|
| AI分身广场 | 平台上所有公开专家分身的卡片展示 |
| 我的分身 | 我创建的个人分身的管理面板 |

### 7.2 AI分身广场（专家卡片）

- 卡片展示：头像 / 姓名 / 职称 / 研究领域 / 简介 / 累计对话次数
- 点击卡片 → 进入该专家的「新建对话页」（类型 B）

### 7.3 我的分身（管理面板）

左侧是分身列表，右侧是选中分身的详情面板。

**分身列表**：
- 显示所有分身，包括构建中的
- 构建中的分身显示进度条 + 「构建中」标签
- 点击切换右侧详情

**右侧详情面板（5 个子 Tab）**：

| 子Tab | 用途 |
|-------|------|
| 基本信息 | 编辑名字、头像、职称头衔、研究领域、所在院系、简介、主页链接 |
| 知识库 | 上传/删除知识文件；支持文件上传、网页链接、网盘链接、公众号订阅四种方式 |
| 设置 | 编辑 AI 人设、初始欢迎语、推荐问题（可手动添加或 AI 智能生成）、禁答范围、联网搜索开关、语音通话开关、声音克隆 |
| 总结 | 分身接待访客的数据汇总（访客数、对话轮次、热门话题、回复安全报告）；**仅上架广场后可见** |
| 历史会话 | 查看访客和分身的聊天记录；**仅上架广场后可见** |

### 7.4 分身状态流

```
创建 → 「构建中」（进度 0% → 100%）→ 「已完成」（可对话）
```

- 构建中：侧边栏不显示，广场管理面板可见，功能禁用
- 完成后：侧边栏出现该分身入口，可发起对话

### 7.5 广场上架 / 下架

```
私密状态 → 申请上架 → 审核中 → 审核通过 → 公开上架
                                         ↑
                                    可主动下架 → 恢复私密
```

- 上架后「总结」和「历史会话」两个 Tab 才会启用
- 下架操作需确认弹窗

## 八、创建分身（persona-distill）

**入口**：侧边栏「+ 创建分身」 / 分身广场右上角「创建分身」按钮

- 多步骤向导式填写流程（名字、简介、上传知识文件等）
- 提交后进入「构建中」状态，系统模拟构建进度
- 构建完成后，侧边栏自动出现新分身入口，可进入「我的分身」管理面板查看

## 九、关键流程图

### 流程 A：Agent 新建对话

```
点击「新建对话」
       ↓
打开新建对话页（历史记录无变化）
       ↓
输入内容 → 点击发送
       ↓
创建对话记录 → 跳转到对话详情页
（历史列表同步出现新记录）
```

### 流程 B：与分身/专家新建对话

```
侧边栏点击分身 / 广场点击专家卡片
       ↓
打开分身欢迎页（展示介绍卡片，历史记录无变化）
       ↓
发送第一条消息
       ↓
创建对话记录 → 跳转到对话详情页
（历史列表同步出现新记录，带彩色分身 Badge）
```

### 流程 C：在已有对话中 @ 协同

```
打开某条 Agent 历史对话
       ↓
底部输入框选择 @ 召唤，或直接输入 @名字
       ↓
发送消息
       ↓
AI 回复以「协同咨询」格式呈现，包含被咨询方的引用块
（此对话类型仍为 Agent 对话，历史 Badge 不变）
```
