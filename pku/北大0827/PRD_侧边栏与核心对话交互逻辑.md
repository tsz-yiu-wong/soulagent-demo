## 1. 产品概述与设计目标

### 1.1 产品定位
SoulAgent 是一款集**通用智能助手（Agent）**、**个人定制分身**与**行业专家分身**于一体的多智能体协同工作平台。用户既可以与全能的主 Agent 协同完成复杂长链路任务，也可以直接与垂直领域的专业分身进行沉浸式 1v1 探讨，或者召集多位专家进行群聊研讨。

### 1.2 核心设计原则
1. **轻量即时（Zero-Ghost-Chat）**：避免产生大量无内容的空白会话。点击“新建”仅提供输入面板与引导，只有在产生实质交互（发送首条消息）后才正式建立会话记录。
2. **场景分流（Dual-Mode Clarity）**：清晰区分“主 Agent 协同对话”与“垂直分身直聊”两种产品形态，在视觉排版、人设展现、输入工具栏与上下文逻辑上形成明确的心智区隔。
3. **沉浸与引导（Smart Guidance）**：针对不同分身特长，动态提供定制化的 Prompt 气泡与人设名片，降低用户提问门槛。

## 3. 侧边栏产品与交互规范

侧边栏为全局常驻导航组件，位于屏幕左侧（固定宽度 250px），自上而下分为四个主要区域。

```
+------------------------------------+
|  [ 品牌 Logo ]                     |  -> 点击回到主 Agent 新建页
+------------------------------------+
|  [ ✨ 新建对话 ]                   |  -> 独立高亮操作条
+------------------------------------+
|  AI分身                            |  -> 分身广场总入口
|    ├── [诗] 我的写诗分身            |
|    ├── [具] 我的具身AI分身          |  -> 个人专属分身列表（点击进入专属新对话）
|    ├── [码] 代码审计分身            |
|    └──  +  创建分身                |  -> 进入分身构建流程
+------------------------------------+
|  历史对话                          |
|    ├── [群聊] 具身智能架构探讨      |  -> 红色渐变 Badge
|    ├── [专家名] 视觉算法演进探讨    |  -> 专家专属色 Badge
|    ├── [分身名] 七言律诗创作        |  -> 分身专属色 Badge
|    └── 💬 智能系统预测模型探讨      |  -> 默认气泡图标 (主 Agent 会话)
+------------------------------------+
```

### 3.1 区域划分与交互逻辑

#### 区域 1：Logo 品牌区
- **展示**：产品 Logo。
- **交互**：点击直接跳转至“主 Agent 新建对话页”。

#### 区域 2：新建对话（主入口）
- **展示**：白色卡片样式独立操作条，带高亮描边与星芒图标。
- **核心生命周期规则（会话延迟创建）**：
  - **点击前/未发消息**：点击后进入“主 Agent 新建对话页”。**此时侧边栏历史列表中不会生成任何空会话项**。若当前已在新建页，点击则清空当前输入并聚焦，同时随机刷新下方的推荐问题。
  - **发送首条消息后**：系统根据用户输入内容自动生成会话标题，并在侧边栏历史列表顶端动态插入新会话项（激活状态），页面无缝进入会话详情。

#### 区域 3：AI 分身体系导航组
- **“AI分身”总入口**：点击跳转至分身广场页。
- **个人分身子列表**：
  - 展示用户已创建成功的个人分身（处于构建中的分身不展示）。
  - 每个子项展示分身专属渐变头像与分身名称。
  - **点击行为**：点击进入对应分身的**专属新建对话页**。同样**不立即在历史列表中生成记录**，直到用户发送首条提问。
- **“+ 创建分身”入口**：位于分身子列表末尾，点击进入分身创建与提炼流程。

#### 区域 4：历史对话列表
- **展示规则**：按创建时间倒序排列（最新会话在最上方），超出视窗高度支持内部滚动。
- **差异化会话徽章（Badges）**：
  - **群聊会话**：展示红色渐变 `群聊` 徽章。
  - **个人分身会话**：展示该分身专属渐变色的 `{分身名称}` 徽章。
  - **专家分身会话**：展示该专家专属主题色的 `{专家名称}` 徽章。
  - **主 Agent 协同会话**：展示标准聊天气泡图标。
- **交互**：点击任意历史项，直接加载该会话的历史消息流，并在侧边栏呈现高亮选中态（`.active`）。

## 4. 核心对话体系与样式规范 (Dual Chat Paradigm)

系统严格区分两套对话样式与交互流：**主 Agent 协同体系** 与 **分身直聊体系**。

---

### 4.1 主 Agent 对话体系（协同对话模式）

主 Agent 面向通用问题解答与跨分身协同调度。

#### 1. 主 Agent 新建对话页
- **视觉布局**：
  - 页面中央呈现亲切问候语（如：“TY，今天需要帮你做什么”）。
  - 中间为多功能输入卡片，支持文本输入与附件上传。
  - 输入框下方排列 3 个**技术洞察推荐卡片**，展示高价值议题。用户点击卡片即可一键填入内容并自动发起对话。
- **底部协同选择器**：
  - **“AI分身”下拉选择器**：聚合展示“我的专属分身”与“行业专家分身”。用户点击某分身项后，系统自动在输入框头部插入 `@分身名 ` 唤起指令。
- **会话生成规则**：
  - 用户输入内容并点击“发送”（或按 `Enter`）后，提取提问摘要（前 20 字符）生成标题，侧边栏新增普通会话项，页面跳转至对话详情。

#### 2. 主 Agent 历史/对话详情页
- **视觉特征**：
  - 顶部不展示个人名片，保持大面积纯净消息流。
  - 用户消息靠右（浅灰气泡），Agent 消息靠左（通栏排版）。
- **多智能体协同咨询机制（@分身交互）**：
  - 用户在输入框中输入 `@某分身` 发送后，主 Agent 触发协同咨询协议：
    1. **分身专属引用块**：以带分身主题色边框的引用卡片形式，展示该分身的专业解答（如写诗分身输出诗词格律、具身分身输出控制架构）。
    2. **Agent 综合分析**：主 Agent 对分身观点进行归纳提炼。
    3. **推进建议**：主 Agent 给出下一步落地方案或实验排期建议。
- **底部输入区**：继续常驻 `@ 召唤分身/专家` 选择器，允许在同一会话中持续邀请其他分身加入探讨。

---

### 4.2 分身对话体系（个人分身 & 专家分身）

分身体系面向垂直场景沉浸式交流，涵盖“用户自建的个人分身”与“平台入驻的专家分身”。

#### 1. 角色分类定义
- **个人专属分身 (My Clones)**：用户通过上传自身知识库、设定性格与系统提示词定制而成，具备管理与上架广场的权限。
- **行业专家分身 (Expert Twins)**：平台已上架的高校学者或权威专家，具备公开职称、研究方向与权威学术知识库。

#### 2. 分身专属新建对话页
- **视觉布局（大名片聚焦）**：
  - 居中展示**分身专属介绍大名片**：
    - 大尺寸圆形渐变头像（或真人/形象图片）。
    - 分身全称与角色身份标签（如：`文学创作 · 我的分身` 或 `教授 · 博士生导师`）。
    - 结构化标签栏（职称标签 + 专业研究领域标签）。
    - 详细的专长简介与学术背景说明。
  - **定制 Prompt 气泡（Prompt Chips）**：在名片下方提供 3 个针对该分身量身定制的典型提问气泡（例如写诗分身提供“七言绝句创作”，代码审计分身提供“并发死锁排查”）。点击即可直接触发首轮对话。
  - **输入框**：占位符自适应为 `给 {分身名} 发送消息...`。
- **顶部操作栏权限差异**：
  - **个人分身场景**：
    - **[管理分身] 按钮**：点击跳转至分身广场中的“我的分身”管理面板，查看知识库与配置。
    - **[申请上架到 AI 分身广场] 按钮**：未上架时显示申请按钮，点击弹出申请表单（填写联系方式与申请理由）；提交后变为“上架审核中”；已上架则显示“已上架至广场”徽章。
  - **专家分身场景**：
    - 页面左上角显示 **[返回 AI 分身广场]** 导航链接。

#### 3. 分身历史/对话详情页
- **视觉特征**：
  - **顶部常驻名片**：消息流最上方保留分身名片与 3 个 Prompt 气泡，便于用户随时回顾人设或追问。
  - **1v1 沉浸式气泡流**：助手回复左侧展示分身专属头像框，采用分身第一人称口吻进行专业解答。
- **输入栏极简设计**：
  - 分身对话详情页底部**自动隐藏** `@ 召唤选择器`，杜绝在单分身会话中混入其他角色，保证纯粹的 1v1 沉浸直聊体验。

---

### 4.3 衍生模式：多专家协同群聊

- **发起方式**：用户在 AI 分身广场勾选 2 位及以上专家，在底部悬浮栏点击“发起群聊”并输入共同议题。
- **群聊交互规则**：
  - 侧边栏生成带红色 `群聊` 徽章的会话记录。
  - 详情页中，各入选专家**按照拟人化时序依次思考并轮流发言**：
    1. 展示当前专家的思考打字动画（`typing-dots`：“正在思考并组织见解...”）。
    2. 间隔约 1.2 秒后输出该专家的学术观点，带有专属头像、姓名与职称标注。
    3. 自动流转至下一位专家，呈现多学科专家圆桌研讨的效果。

## 6. 业务规则与边界交互

### 6.1 会话命名与防重规则
1. **自动摘要命名**：会话标题默认提取首条用户消息的前 20 字符。若提问以 `@分身名` 开头，自动去除 `@` 前缀提取纯问题文本。
2. **重名递增防冲**：若历史列表中已存在完全相同的会话标题，系统自动在标题后追加自增编号，如 `智能仿真探讨 (1)`，确保每个会话唯一可寻址。

### 6.2 输入与发送交互
1. **空内容保护**：输入框为空或纯空白字符时，点击发送按钮或按快捷键均不触发任何动作。
2. **快捷键规范**：
   - `Enter`：立即发送消息。
   - `Shift + Enter`：输入框内换行。
3. **输入中防重复提交**：群聊多专家生成过程中或消息流传输中，输入框与发送按钮暂时置灰禁用，防止时序错乱。

### 6.3 状态同步与隔离
1. 处于“构建中”的分身仅在分身广场的“我的分身”中显示进度条，不会出现在侧边栏导航树中，避免用户误点进入半成品状态。
2. 分身一旦构建完成，自动通过全局事件刷新侧边栏与广场，用户可无缝发起对话。
