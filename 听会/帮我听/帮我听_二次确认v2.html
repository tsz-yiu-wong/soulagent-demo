帮我听 — 二次确认方案 v2

方案 A：下方气泡
已解析 3 个音频资源
发送与联动逻辑说明
1. 粘贴 / 输入链接 → 检测到 URL → 发送按钮短暂 loading → 解析结果填入下方气泡
2. 气泡里点 × 移除某项 → 输入框对应那行 URL 同步删掉，计数更新
3. 全部移除 → 气泡关闭，输入框也清空
4. 气泡开着时再粘贴新链接 → 新结果追加到气泡（不覆盖旧的）
5. 点「确认听取」→ 所有剩余项提交，输入框 + 气泡一起清空
方案 B：输入框 Tag 化
逻辑说明
1. 粘贴链接 → 检测到 URL → 输入框内就地替换成可删除的 chip，无弹层
2. chip 上点 × → 该链接从队列移除，发送按钮计数减一
3. 可继续在 chip 后输入文字，或再粘贴更多链接（每条单独成 chip）
4. Backspace 删除最后一个 chip（光标在输入框空白时）
5. 发送按钮动态显示链接数，点击即提交，没有额外弹层
💡 点击上方「模拟粘贴」按钮体验两种方案的完整交互
