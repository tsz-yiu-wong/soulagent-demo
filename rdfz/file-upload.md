# 资料上传功能 PRD

**产品名称**：SoulAgent 教师资料上传系统  
**文档版本**：v1.1  
**最后更新**：2026-07-05  
**文档状态**：待评审

---

## 一、背景与目标

SoulAgent 面向教师提供两类 AI 能力：**AI 分身构建**（让 AI 还原教师的知识与表达风格）和 **Agent 听课**（让 AI 理解课堂内容辅助教学）。本功能模块负责教师资料的录入与管理，是两类 AI 能力的数据基础。

**核心目标：**
- 提供简洁、安全的资料上传入口，降低教师使用门槛
- 支持文件与链接两种资料形式，覆盖多种内容载体
- 通过手机号绑定实现数据持久化与跨设备回显

---

## 二、用户流程总览

```
后台生成带 Token/API-Key 的专属 URL（长期有效）
        ↓
教师收到链接，访问该 URL
        ↓
Page 0：手机号登录 / 注册（首次绑定手机号）
        ↓
Page 1：选择上传类型
    ├─ 【Agent 听课】资料上传 → Page 2（课程信息上传）
    └─ 【AI 分身构建】资料上传 → Page 3（个人信息填写）→ Page 4（个人资料上传）
```

## 三、功能模块详细说明

### 3.1 访问鉴权与入口

#### 3.1.1 专属链接机制

| 项目 | 说明 |
|------|------|
| 链接生成方 | 后台运营人员 |
| 链接形式 | 带 Token 或 API-Key 的专属 URL（每位老师唯一） |
| 链接用途 | 身份鉴权 + 资料归属绑定 |
| 有效期 | 长期有效 |

---

### 3.2 Page 0 – 手机号登录 / 注册

#### 3.2.1 页面功能

教师通过专属链接访问后，需完成手机号登录；首次访问时即完成注册与绑定；后续使用同一手机号登录可恢复全部历史上传数据。

#### 3.2.2 表单字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 手机号 | 文本输入 | 11 位数字，格式校验 |
| 验证码 | 文本输入 | 配合「获取验证码」按钮 |

#### 3.2.3 「获取验证码」按钮行为

| 状态 | 行为 |
|------|------|
| 默认 | 可点击，文案「获取验证码」 |
| 手机号为空 | Toast 报错「请输入手机号」，聚焦手机号输入框，不发送 |
| 手机号格式错误 | Toast 报错「请输入正确的11位手机号」，不发送 |
| 发送成功 | 按钮禁用，60 秒倒计时，文案显示「N s」；Toast「验证码已发送」 |
| 倒计时结束 | 按钮恢复可用，文案复原「获取验证码」 |

#### 3.2.4 「登录/注册」按钮行为

- 手机号或验证码为空时，按钮置灰不可点击
- 两项均填写后按钮激活，点击后页面淡出，跳转 Page 1；Toast「账号登录成功」

#### 3.2.5 账号逻辑

- **首次登录**：自动完成注册 + 实例绑定
- **已注册用户**：直接登录，**自动回显该手机号下所有历史上传的文件**

### 3.3 Page 1 – 选择上传类型

登录成功后展示，包含两张卡片：

| 卡片 | 图标 | 标题 | 副标题 |
|------|------|------|--------|
| Agent 听课 | 📚 | 【Agent 听课】资料上传 | 上传课程信息、课件教案等资料 |
| AI 分身构建 | 👤 | 【AI 分身构建】资料上传 | 填写个人信息，上传公开课、演讲等资料 |

- 卡片悬停：上浮 4px + 阴影加深
- 点击 Agent 听课 → Page 2（课程信息上传）
- 点击 AI 分身构建 → Page 3（个人信息填写）

---

### 3.4 Page 2 – 课程信息上传（Agent 听课流程）

#### 3.4.1 表单字段

所有字段均为选填，无必填校验，随时填写随时保存。

| 字段 | 类型 | 说明 |
|------|------|------|
| 学科 | 文本输入 | 如「语文」 |
| 课程主题 | 文本输入 | 如「古代诗歌鉴赏」 |
| 课程时间 | 日期时间范围选择器 | 开始时间 — 结束时间（含日期+时间） |
| 授课老师 | 文本输入 | 支持多位老师，如「张三老师、李四老师、王五老师」 |
| 课件 | 文件上传（多选） | 支持批量上传多个文件 |
| 教案 | 文件上传（多选） | 选填；教案为保密资料，不会作用于对话回复。 |

#### 3.4.2 文件上传交互

- 课件、教案字段各有「+ 上传文件」虚线按钮，点击触发文件选择器
- 支持批量选择多个文件（无数量限制）
- 已选文件以列表方式展示在按钮上方，每项右侧有删除按钮（×）
- 删除已选文件需二次确认弹窗（见 4.3）

#### 3.4.3 保存操作

- 页面为信息录入页，无必填校验，填写任意内容均可保存
- 点击「保存」后，直接保存当前页面所有内容，Toast「保存成功」
- 支持多次保存，后次保存覆盖前次内容

#### 3.4.4 未保存离开保护

页面内有任意字段变动且未保存，用户尝试离开时，弹出确认弹窗（见 4.2）。

### 3.5 Page 3 – 个人信息填写（AI 分身构建流程）

#### 3.5.1 表单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 已绑定手机号 | 只读展示 | — | 格式化显示（如 138 0000 0000），不可修改 |
| 头像 | 图片上传 | 是 | 点击圆形区域触发文件选择；支持 JPG、PNG，建议正方形 |
| 名字 | 文本输入 | 是 |  |
| 标签 | 文本输入 | 否 | 如「特级教师」，多标签用中文分号或英文分号分割 |
| 岗位 | 文本输入 | 是 | 如「化学科科主任」 |
| 简介 | 多行文本 | 是 | 个人简介 |
| 教学学科 | 文本输入 | 是 | 多学科用分号分割 |

#### 3.5.2 专家卡片实时预览

- 位于页面顶部区域，与表单同屏展示
- 实时同步名字、标签、岗位、简介、教学学科
- 头像上传后实时同步到预览卡片的头像区域
- 字段为空时显示灰色占位文字

#### 3.5.3 未保存离开保护

页面内有任意字段变动且未保存，用户尝试离开时，弹出确认弹窗（见 4.2）。

#### 3.5.4 下一步

- 按钮文案：「下一步：上传资料」
- 通过后：淡出动画 → 跳转 Page 4

### 3.6 Page 4 – 个人资料上传（AI 分身构建流程）

#### 3.6.1 资料类型选择

两个类别 Tab（单选，默认选中「课程资料」）：

| 类别 | 图标 | 资料举例 | 用途说明 |
|------|------|---------|---------|
| 课程资料 | 📚 | 课程文档、课件、公开课视频、优质课视频、教案文档 | 使分身更完整地理解课程内容，使课程相关问题回答更准确、专业，与授课内容尽量保持一致 |
| 其他公开资料 | 📄 | 演讲、播客、访谈、新闻报道、论文、报刊、期刊 | 使分身学习在公开分享中的表达方式和思考习惯，更自然地还原讲课风格和沟通特点 |

- 选中状态：高亮边框（品牌红色）+ 背景淡红 + 右上角勾选标识
- 切换类别后，上传区域下方支持格式标签随之更新

#### 3.6.2 上传模式切换

顶部 Segmented Tab：「上传文件」/ 「添加链接」，切换时对应面板显示/隐藏。

---

#### 3.6.3 上传文件模式

**拖拽上传区（Dropzone）：**
- 支持拖拽文件到区域内（拖入时边框高亮 + 轻微放大 + 背景加深）
- 支持点击区域唤起本地文件选择器
- 支持批量选择/批量拖入多个文件，无文件数量与单文件大小限制
- 选择完成后自动加入文件列表，开始并行上传

**支持格式（课程资料）：**
`HTML` `PDF` `PPT / PPTX` `DOC / DOCX` `TXT` `PNG / JPG / JPEG` `MP4 / AVI / FLV / MKV / MOV`

**支持格式（其他公开资料）：**
`HTML` `PDF` `PPT / PPTX` `DOC / DOCX` `TXT` `PNG / JPG / JPEG` `MP4 / AVI / FLV / MKV / MOV`

---

#### 3.6.4 添加链接模式

**多行 Textarea 输入框：**
- 高度与文件上传区对齐（约 236px）
- 占位提示文案：
  ```
  请输入链接，多个链接可通过换行或分号分隔。
  例如：
  https://www.bilibili.com/video/BV1xx...
  https://mp.weixin.qq.com/s/...
  ```

**分隔符支持（可混合使用）：**

| 分隔符 | 说明 |
|--------|------|
| 换行符 `\n` | 回车换行 |
| 英文分号 `;` | 半角分号 |
| 中文分号 `；` | 全角分号 |

**「添加链接」按钮逻辑：**
1. 读取 Textarea 内容，按上述分隔符拆分为多条 URL
2. 逐条校验 URL 格式（有效性验证）
3. 有效 URL 加入文件列表，以链接形式展示（仅显示 URL，不做内容抓取或预览）
4. 无效 URL 过滤，并在 Toast 中提示「已过滤 N 个无效链接」
5. Textarea 清空

**快捷键：** `Ctrl/Cmd + Enter` 触发添加

---

### 3.7 已上传文件列表

#### 3.7.1 列表展示规则

- **排序：按上传时间倒序排列**（最新上传的置顶）
- 登录后自动回显该手机号下所有历史上传文件（无数量上限）
- 列表顶部显示「已添加 **N** 个文件」，实时更新

#### 3.7.2 文件列表项结构

每条文件项从左到右依次包含：

```
[图标] [文件名]           [状态/大小]    [保密—公开 Toggle]  [🗑删除]
```

**图标状态：**

| 场景 | 图标表现 |
|------|---------|
| 上传中 | 旋转加载动画（Spinner，品牌色） |
| 上传完成 且 公开 | 文件类型 Emoji（见类型映射表） |
| 上传完成 且 保密 | 匿名图标（遮脸造型，品牌红色） |

**文件类型 Emoji 映射：**

| 格式 | Emoji |
|------|-------|
| PDF | 📕 |
| PPT / PPTX | 📊 |
| DOC / DOCX | 📝 |
| TXT | 📃 |
| MP4 / MKV / MOV | 🎬 |
| MP3 / M4A / WAV | 🎵 |
| JPG / JPEG / PNG | 🖼️ |
| 链接 | 🔗 |
| 其他 | 📁 |

**状态文字：**

| 状态 | 展示文字 |
|------|---------|
| 上传中 | 🔴 上传中… · 文件大小 |
| 上传完成 | 文件大小 |
| 上传失败 | 🔴 上传失败（同时 Toast 报错提示，列表自动移除该文件，用户需手动重新上传） |

#### 3.7.3 保密 / 公开 Toggle

仅在文件上传完成后显示，上传中不展示。

| 状态 | Toggle 位置 | 图标 | 含义 |
|------|------------|------|------|
| 公开（默认） | 右侧（checked） | 文件类型 Emoji | 该文件参与 AI 对话回复 |
| 保密 | 左侧（unchecked） | 匿名 icon | 该文件不参与 AI 对话回复 |

保密状态可随时切换（公开 ⇄ 保密）。

**ⓘ Info 图标 Tooltip（仅「保密」标签旁）：**

> 「保密状态下，该文件不会作用于对话回复。」

- 悬停 Info 图标时，弹出 Tooltip（从图标上方弹出，带淡入动画）
- Info 图标默认灰色，悬停时变为品牌红色

#### 3.7.4 删除文件

点击任意文件项的删除图标（🗑），触发二次确认弹窗（详见 4.3）：

- **上传中的文件**：确认后**中断上传进程**（取消对应 HTTP 请求），并移除列表项
- **已完成的文件**：确认后移除列表项及对应后端数据

## 四、全局交互规范

### 4.1 页面导航动画

| 操作 | 动画效果 |
|------|---------|
| 进入新页面 | 淡入 + 向上平移（280ms） |
| 离开当前页 | 淡出 + 向上平移（220ms） |

### 4.2 未保存离开保护（全局）

**适用页面：** Page 2（课程信息上传）、Page 3（个人信息填写）

**触发条件：** 页面有信息变动且未保存，用户尝试：
- 点击返回/导航按钮
- 浏览器返回键
- 关闭或刷新浏览器标签页（监听 `beforeunload`）

**确认弹窗规格：**

```
┌──────────────────────────────┐
│         确认离开？              │
│                               │
│  当前页面的修改尚未保存，        │
│  离开后数据将丢失。             │
│                               │
│   [继续离开]    [留在此页]      │
└──────────────────────────────┘
```

- 「留在此页」：主按钮（品牌色）
- 「继续离开」：次要/危险按钮

### 4.3 删除二次确认（全局）

**规则：所有删除操作均须弹窗二次确认，不得直接删除。**

适用场景：
- Page 4 文件列表中删除文件（含上传中文件）
- Page 2 中删除课件/教案文件

**确认弹窗规格：**

```
┌──────────────────────────────┐
│          确认删除？             │
│                               │
│  确认删除「[文件名]」？          │
│  此操作不可恢复。              │
│                               │
│      [取消]    [确认删除]       │
└──────────────────────────────┘
```

- 「确认删除」：红色危险按钮
- 「取消」：普通次要按钮
- 上传中文件确认删除后，同时中断上传请求

### 4.4 Toast 通知规范

| 类型 | 适用场景 | 样式 |
|------|---------|------|
| 成功（success） | 登录成功、上传成功、保存成功、链接添加成功 | 左侧绿色边框 |
| 错误（error） | 表单校验失败、格式不正确、无有效链接、上传失败 | 左侧红色边框 |
| 信息（info） | 添加 N 个文件、验证码已发送、含无效链接过滤提示 | 左侧品牌色边框 |

- Toast 从底部居中弹出，持续 3 秒后自动消失（淡出）
- 多条 Toast 纵向堆叠显示

### 4.5 历史数据回显

- 用户通过**同一手机号**登录后，自动加载并回显该账号下所有历史上传的文件
- 文件列表按**上传时间倒序**排列（含历史文件）
- 回显内容包含：文件名、大小/类型标识、上传状态、保密/公开状态

## 五、数据安全说明

**AI 分身构建流程顶部提示：**
> 🛡 资料仅用于构建您的专属分身，数据存储在人大附中专属服务器内，不会共享给任何第三方。

**Agent 听课流程顶部提示：**
> 🛡 资料仅用于 Agent 帮你听课功能，数据存储在人大附中专属服务器内，不会共享给任何第三方。

**保密文件说明：**
- 保密状态下，文件存档但**不参与 AI 对话回复**
- 保密状态可随时切换（公开 ⇄ 保密）
- 该机制仅适用于 Page 4（个人资料上传），Agent 听课流程的课件/教案无此开关

## 六、非功能性要求

| 项目 | 要求 |
|------|------|
| 批量上传 | 单次可选择多个文件，各文件并行上传，无数量限制 |
| 文件大小 | 无单文件大小限制 |
| 文件数量 | 每位老师可上传文件总数无上限 |
| 上传失败处理 | Toast 报错提示，列表自动移除失败文件，用户手动重新上传 |
| 上传中断 | 删除上传中文件时，同时取消对应 HTTP 请求（XHR abort / fetch AbortController） |
| 链接展示 | 仅展示 URL 本身，不做内容抓取或预览 |
| 文件排序 | 列表始终按上传时间倒序，新文件置顶 |
| 响应式 | 移动端（≤ 700px）：类别列表垂直排列，内边距缩减 |
| 动画性能 | 页面切换 ≤ 300ms，Toast 动画 ≤ 300ms |
