# 推荐问管理后台 PRD (产品需求文档)

## 1. 产品概述
- **产品定位**：为运营人员提供一个统一、高效的后台系统，用于管理主智能体（MyAgent）及各个数字分身（专家）在前端界面上展示的“推荐问”（引导用户发起提问的快捷文案）。
- **核心目标**：
  - 支持多配置对象的数据隔离。
  - 满足 MyAgent 复杂的基于槽位和分类的推荐逻辑。
  - 满足数字分身轻量化的推荐问平铺展示逻辑。
  - 支持高效的批量操作（上下架、导入、删除）。

---

## 2. 整体架构与对象隔离逻辑
- **配置对象划分**：
  - **主智能体 (MyAgent)**：支持「分类体系」和「槽位配置」。
  - **数字分身 (专家类，如张三/李四)**：去除分类概念，数据扁平化，**隐藏槽位配置与分类筛选**。
- **数据隔离机制**：
  - 不同对象的推荐问数据完全独立。在左侧边栏切换对象时，右侧的数据列表、筛选条件、批量操作状态等均需重置并拉取当前对象的独立数据。

---

## 3. 核心模块与业务逻辑说明

### 3.1 槽位配置模块（仅 MyAgent 生效）
- **功能描述**：决定客户端（C端）推荐问展示位的拉取策略。假设 C 端预留了 4 个展示位，后台可配置每个展示位（槽位）拉取什么类型的内容。
- **配置字段**：
  - **槽位ID**：顺序编号（1, 2, 3...）。
  - **主分类**：该槽位优先展示的分类（必选）。
  - **兜底分类**：当主分类下的有效（已上架且在生效时间内）推荐问不足时，从该分类补足（可选填「无」）。
- **逻辑规则**：
  - 槽位数量可动态增减。
  - 前端拉取数据时，后台根据槽位配置从对应分类中按**权重倒序**返回推荐问。

### 3.2 推荐问列表与基础管理模块
- **列表显示字段**：
  - 语言 (ZH / EN)、推荐问文案、图标、分类 (仅 MyAgent 显示)、权重、生效时间、状态 (上架/下架)、操作。
- **状态与时效逻辑**：
  - 一条推荐问要在 C 端展示，必须同时满足：**状态为「上架」** 且 **当前时间处于「生效时间」范围内**（如未设置生效时间，则永久有效）。
- **权限与编辑规则**：
  - **语言控制**：底层数据结构由双语变更为单语。一条记录仅对应一种语言（ZH 或 EN）。
  - **权重锁定**：为避免频繁无序地调整排序，当前规定**权重在创建后不可修改**（如需修改，建议下架旧文案并新建）。若业务侧有高频调序需求，后续迭代可放开编辑或增加“拖拽排序”能力。

### 3.3 分类管理模块（仅 MyAgent 生效）
- **功能描述**：管理推荐问的业务归属字典。
- **删除逻辑（核心答疑）**：
  - **问题**：删分类的时候，所有所属分类都删掉吗？
  - **推荐方案（强校验拒绝策略）**：
    - **禁止级联删除**：当运营人员点击删除分类时，系统需校验该分类下**是否仍有关联的推荐问**，或者**是否被槽位配置引用**。
    - 如果存在关联数据，弹窗提示：`“该分类下仍有 X 条推荐问或被槽位配置使用，请先将数据转移至其他分类或修改槽位配置后再尝试删除。”`
    - **原因**：级联删除极其危险，容易导致线上推荐问突然大面积消失。如果强制需要兜底，系统应只允许将关联数据转移到系统内置的「默认」分类中。

### 3.4 批量导入与去重逻辑
- **功能描述**：通过 CSV 文件快速导入大量推荐问。系统提供下载模版的功能（MyAgent 版带分类列，专家版无分类列）。
- **重复文案处理策略（核心答疑）**：
  - **唯一键定义**：以 `(语言 + 推荐问文案 + 配置对象)` 作为数据的联合唯一标识。
  - **问题**：批量导入的时候，重复文案怎么办？
  - **推荐方案（跳过或覆盖选其一）**：
    - 建议在导入确认弹窗中提供复选框：`[ ] 若遇到重复文案，覆盖更新现有数据`。
    - **默认不勾选（跳过策略）**：系统逐行校验，若发现数据库中已存在同语言、同内容的文案，则**直接跳过该行，不做任何处理**。导入完成后提示：“成功导入 X 条，跳过 Y 条重复数据”。
    - **勾选后（覆盖策略）**：以导入文件中的最新数据（如图标、分类、权重、状态、时间）为准，更新数据库中的已有记录。
  - **数据校验**：
    - 语言字段只能为 `ZH` 或 `EN`（忽略大小写，落库统一转大写）。
    - 缺少必填项（语言、文案内容）的行直接标记为导入失败并跳过。

### 3.5 图标管理模块
- **功能描述**：维护图标标识库，供推荐问选用。
- **业务逻辑**：
  - 支持上传图片并绑定一个英文字母组合作为标识（Key）。
  - 推荐问通过 Key 关联图标。如果图标在管理库中被删除，正在使用该图标的推荐问不会被删除，但前端将不再渲染图标（降级为无图标状态）。

---

## 4. 异常处理与系统边界
- **分页限制**：查询列表支持分页，避免单次拉取数据过多导致渲染卡顿，每页建议 10-20 条。
- **批量操作数量上限**：为了防止误操作及锁表，单词批量操作（删除、上下架）建议限制在当前页的数据（全选当前页），或硬限制每次最多操作 500 条。
- **安全性**：要求记录后台的操作日志，特别是「批量删除」和「分类删除」等高危操作，记录操作人、操作时间及变更内容，以便追溯。
