关键功能点详解
1

输入框新增选择维度

在传统的【模型】和【技能】选择之外，加入【专家分身】指派下拉，使用户无需退出当前会话即可享受专业分身的解答。

2

双头像重叠联合设计

专家大头像处于上层，主 Agent 小标紧随右下。直观表现“专家解答，但仍在 Agent 会话体系内监督运行”的代理心智模型。

3

专属光环边框与主题样式

专家气泡采用独特微弱发光边框，配以“专家分身回复”的亮金色标签，一眼区别于主 Agent 的常规纯白/灰色对话泡。

4

任务指派过渡卡片 (Trace)

当指令下发时，显示中转动画，让用户感知到 Agent 正在调度底层专家技能进行思考，缓解回答延迟焦虑并建立专业度心智。

5

可查看的调用链路面板

气泡底端支持展开查看详细的技术调用 Trace，包括调用的函数、底层大模型、耗时及 Token，做到黑盒过程透明化。
